SUPABASE DATABASE SCHEMA (create exactly these tables)
=======================================================================

TABLE: disputes
  id                    UUID PRIMARY KEY DEFAULT gen_random_uuid()
  created_at            TIMESTAMPTZ DEFAULT NOW()
  updated_at            TIMESTAMPTZ DEFAULT NOW()
  buyer_id              TEXT NOT NULL
  seller_id             TEXT NOT NULL
  logistics_id          TEXT NOT NULL
  order_id              TEXT NOT NULL
  dispute_type          TEXT NOT NULL  -- enum: DAMAGED_ITEM, WRONG_ITEM, 
                                       --   NOT_DELIVERED, REFUND_DENIED
  status                TEXT NOT NULL DEFAULT 'PENDING'
                                       -- PENDING, EVIDENCE_COLLECTION,
                                       -- NEGOTIATION, RESOLVED, ESCALATED
  decision              TEXT           -- FULL_REFUND, PARTIAL_REFUND,
                                       --   REJECTED, PENDING
  dispute_amount_inr    NUMERIC(10,2) NOT NULL
  refund_amount_inr     NUMERIC(10,2)
  reasoning             TEXT
  confidence_score      NUMERIC(4,3)
  hindsight_session_id  TEXT
  total_cost_inr        NUMERIC(8,4)
  budget_inr            NUMERIC(8,2) DEFAULT 5.00
  escalated_to_human    BOOLEAN DEFAULT FALSE
  agent_run_id          UUID

TABLE: evidence
  id                UUID PRIMARY KEY DEFAULT gen_random_uuid()
  dispute_id        UUID REFERENCES disputes(id)
  submitted_by      TEXT NOT NULL  -- 'buyer' | 'seller' | 'logistics'
  evidence_type     TEXT NOT NULL  -- 'image_url' | 'text' | 'tracking_data'
  content           TEXT NOT NULL
  submitted_at      TIMESTAMPTZ DEFAULT NOW()

TABLE: audit_events
  id                UUID PRIMARY KEY DEFAULT gen_random_uuid()
  dispute_id        UUID REFERENCES disputes(id)
  event_type        TEXT NOT NULL
  actor             TEXT NOT NULL  -- 'agent' | 'buyer' | 'seller' | 
                                   --   'logistics' | 'system'
  payload           JSONB
  timestamp         TIMESTAMPTZ DEFAULT NOW()

TABLE: agent_runs
  id                UUID PRIMARY KEY DEFAULT gen_random_uuid()
  dispute_id        UUID REFERENCES disputes(id)
  started_at        TIMESTAMPTZ DEFAULT NOW()
  completed_at      TIMESTAMPTZ
  status            TEXT DEFAULT 'RUNNING'
  cascadeflow_audit JSONB  -- stores full cascadeflow_audit.json here too

FULL API CONTRACT (all endpoints I must build)
=======================================================================

── DISPUTE LIFECYCLE ──────────────────────────────────────────────────

POST   /api/v1/disputes
  Body: DisputeRequest (from shared/schemas.py)
  Response: DisputeResponse + 201
  Action: Create dispute in DB, trigger agent async, return immediately

GET    /api/v1/disputes/{dispute_id}
  Response: Full dispute object with current status

GET    /api/v1/disputes
  Query: ?status=PENDING&limit=20&offset=0
  Response: Paginated list of disputes

PATCH  /api/v1/disputes/{dispute_id}/status
  Body: {"status": "ESCALATED", "reason": "..."}
  Response: Updated dispute

── AGENT BRIDGE ───────────────────────────────────────────────────────

POST   /api/v1/disputes/{dispute_id}/arbitrate
  Action: (Re)trigger agent run for a dispute
  Response: {"agent_run_id": "uuid", "status": "STARTED"}

GET    /api/v1/disputes/{dispute_id}/agent-status
  Response: {
    "run_id": "uuid",
    "status": "RUNNING|COMPLETE|FAILED",
    "current_stage": "EVIDENCE_COLLECTION|NEGOTIATION|DECISION",
    "stages_completed": ["EVIDENCE_COLLECTION"],
    "elapsed_seconds": 12
  }

── REAL-TIME STREAMING ────────────────────────────────────────────────

GET    /api/v1/disputes/{dispute_id}/stream
  Protocol: Server-Sent Events (text/event-stream)
  Events emitted:
    event: status_update
    data: {"status": "NEGOTIATION", "message": "Agent contacting seller..."}

    event: cost_update
    data: {"total_cost_inr": 1.24, "budget_remaining_inr": 3.76}

    event: decision
    data: {"decision": "FULL_REFUND", "refund_amount_inr": 500.0}

    event: complete
    data: {"dispute_id": "...", "final_status": "RESOLVED"}

── AUDIT ──────────────────────────────────────────────────────────────

GET    /api/v1/disputes/{dispute_id}/audit-trail
  Response: List of all audit_events ordered by timestamp

GET    /api/v1/disputes/{dispute_id}/cascadeflow-audit
  Response: Full cascadeflow_audit.json content for this dispute
